# CSS-Animation-Playground
A board of six small animations, each shown in its own tile.
Animation	Technique
Spinner	rotate with infinite loop
Bouncing dots	translateY with animation-delay
Pulse ring	scale and opacity on a ::after pseudo-element
Flip card	3D rotateY with perspective on :hover
Progress bar	animating width
Equalizer	scaleY with a different duration per bar
